# Tablet interface

**Status: planned; no tablet client exists.**

Treat a tablet as a distinct display/input target, not as evidence that all tablet camera/runtime combinations are supported. First choose whether the tablet captures video or acts as a remote display/controller for a host. Document supported OS/device tiers, network assumptions, controls, accessibility, and privacy before implementation. Reuse the future session/task boundary from the [web interface](web.md) where appropriate; keep model contracts platform-neutral.
